Zahlung einrichten
Sie können Anwendungen über Ihr Mobilfunkkonto oder per Kreditkarte bezahlen. Ihr Mobilfunkanbieter setzt u. U. eine Preisgrenze für jede Transaktion.
Zum Kauf von Anwendungen müssen Sie eine Kreditkarte benutzen.
Kreditkarteninformationen werden nicht von HP oder auf Ihrem Handy gespeichert, sondern von einem sicheren Zahlungsservice eines Drittanbieters.
Tippen Sie auf „Weiter“, um das Kennwort Ihres HP webOS-Konto einzugeben, das zur Autorisierung von Käufen verwendet wird.
